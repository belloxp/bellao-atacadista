# Lista de Infraestrutura do Sistema

## 1. Software

| Item | Descrição / Versão |
|------|--------------------|
| Sistema Operacional | Windows 10/11, macOS ou Linux |
| Node.js | v18 ou superior (necessário para o fetch nativo no backend) |
| npm | v9 ou superior (gerenciador de pacotes do Node.js) |
| MySQL Server | v8.0 ou superior (banco de dados db_compras) |
| MySQL Workbench | v8.0 (modelagem, engenharia reversa e backup .sql) |
| Express | ^5.2.1 (framework web REST do backend) |
| Sequelize | ^6.37.8 (ORM de integração com o MySQL) |
| mysql2 | ^3.22.5 (driver de conexão MySQL do Sequelize) |
| cors | ^2.8.6 (liberação de requisições entre origens) |
| Chart.js | via CDN (gráficos dinâmicos do relatório gráfico) |
| chartjs-plugin-datalabels | via CDN (rótulos de dados nos gráficos) |
| Visual Studio Code | Editor de código |
| Extensão REST Client | Execução do arquivo teste.http |
| Extensão Live Server | Servir o frontend localmente |
| Git / GitHub | Versionamento do código-fonte (mínimo 5 commits) |
| Navegador Web | Google Chrome, Edge ou Firefox atualizados |

## 2. Hardware (mínimo recomendado para desenvolvimento)

| Item | Especificação |
|------|---------------|
| Processador | Intel Core i3 / AMD Ryzen 3 ou superior |
| Memória RAM | 8 GB (mínimo 4 GB) |
| Armazenamento | 10 GB livres em SSD |
| Rede | Acesso à internet (consumo das APIs externas DummyJSON e CDNs) |
| Monitor | Resolução mínima de 1366x768 |
